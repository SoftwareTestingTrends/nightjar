# S-117: Export the diary as CSV

**As a** NightJar user,
**I want to** download my whole sleep diary as a CSV file,
**so I can** keep my own copy or move it to another app.

| Field | Value |
|---|---|
| Traces to | [BR-07](../requirements/BR-07.md) |
| Status | In test |
| Owner | Product (fictional: Priya N.) |

## Acceptance criteria

- **AC1**: An "Export CSV" button on the home page downloads a file named
  `nightjar-diary-YYYY-MM-DD.csv`, using today's date in the user's current time zone.
- **AC2**: The file has a header row and the same columns as the import:
  `bedtime,wake_time,timezone,notes`.
- **AC3**: Times are ISO 8601 with the UTC offset that applied in that night's own time
  zone, for example `2026-03-01T00:25:00-05:00`.
- **AC4**: Nights are in "night of" order, oldest first.
- **AC5**: Journal notes are exported exactly as entered, including commas, quotes, line
  breaks and non-English text, using standard CSV quoting.
- **AC6**: Importing an exported file into an empty diary gives the same nights.
- **Edge**: An empty diary exports the header row only.
- **Non-functional**: Exporting 1,000 nights takes under 2 seconds.
