# S-114: Bedtime wind-down nudge

**As a** NightJar user,
**I get** a gentle wind-down nudge before my usual bedtime,
**so I can** start relaxing.

| Field | Value |
|---|---|
| Traces to | [BR-07](../requirements/BR-07.md) -> [PR-21](../requirements/PR-21.md) |
| Code | `src/nightjar/nudge.py`, `src/nightjar/sleep_window.py` |
| Tests | see [traceability](../traceability.md) |

## Acceptance criteria

- **AC1**: With 7+ nights of data, the nudge is scheduled `lead` minutes before the
  usual bedtime, in the user's current local time. `lead` is the user's chosen
  wind-down lead (AC5); the default is 45.
- **AC2**: After a time zone change, the nudge follows the new local time from the next day.
- **AC3**: During the user's quiet hours / Do Not Disturb, the nudge is delivered
  silently (flag), not skipped.
- **AC4**: Nudge copy uses only phrases from the claims register.
- **AC5**: The user can choose a wind-down lead of 30, 45 or 60 minutes (default 45;
  existing users keep 45). Any other value is rejected and nothing is saved. The
  choice persists, survives saving other settings, and is shown on the settings form
  and in `/api/nudge`. Nothing the app says about timing contradicts it.
- **Edge**: Fewer than 7 nights -> no nudge.
- **Non-functional**: Correct across daylight-saving transitions (spring forward and
  fall back) in America/Toronto and Europe/London. Uses `zoneinfo`; "now" is injected
  so tests control the clock.

## Notes

There is no real push notification. `next_nudge(user, nights, now)` returns
`Nudge(at, silent, text)` and the page shows "Your next wind-down nudge: 22:15"
(for a 23:00 bedtime and the default 45-minute lead).

Requirement change (PR-21 item 3, AC1): the lead was fixed at 45 minutes; approved by
Priya N. (Head of Product) as user-chosen 30/45/60, default 45.

Accepted behaviours (pinned by tests, not fixed):
- Quiet hours are judged at the time the nudge is delivered, so a longer lead can make
  a nudge silent or not silent; it is never skipped.
- Changing the lead mid-evening can cost tonight's nudge if the new time has passed.
- On spring-forward night, a 02:30-04:00 bedtime can put the nudge at or after bedtime.
  Clamping is a separate follow-up.
- Nudge copy never mentions the lead (no register change).
